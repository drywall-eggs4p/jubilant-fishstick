# Reloaded dark UI — Figma-ready design package

Редактируемая реконструкция общей стилистики интерфейса из ролика **Neverlose CS2: Reloaded**, без инвентаря.

## Файлы

- `01-main-settings.svg` — основной экран настроек, 1920×1080.
- `02-presets.svg` — библиотека пресетов, 1920×1080.
- `03-hud-states.svg` — игровые HUD-модули и активные/неактивные состояния, 1920×1080.
- `04-ui-kit.svg` — палитра, типографика, кнопки, поля, карточки и навигация, 1600×1200.

## Импорт в Figma

1. Создайте новый Design file.
2. Перетащите SVG-файлы на холст или выберите **File → Place image**.
3. После импорта нажмите **Ungroup** один раз, если нужны отдельные верхнеуровневые группы.
4. Сохраните цвета из `04-ui-kit.svg` как Color Styles.
5. Преобразуйте группы `Buttons`, `Controls`, `Navigation` и `Surface Components` в компоненты.

SVG содержит именованные группы, поэтому основные слои сохраняют понятные названия после импорта. Текст остаётся редактируемым. Используется `Inter`; при отсутствии шрифта Figma предложит замену.

### Геометрия

- Базовая сетка: 8 px.
- Радиус контролов: 8–9 px.
- Радиус карточек и HUD: 12 px.
- Радиус главного окна: 16 px.
- Граница: 1 px, холодный серо-синий цвет.
- Акцент применяется только к выбранным и активным элементам.

### Типографика

- Экранный заголовок: Inter 17–24 / 650–700.
- Заголовок карточки: Inter 12 / 650.
- Основная подпись: Inter 10.5–11 / 500–600.
- Служебная подпись: Inter 9–10 / 400–500.
- Категория: Inter 9–10 / 700, tracking 1.2 px.

## Примечание

Пакет воспроизводит композицию и визуальный язык интерфейса по кадрам видео: тёмные графитово-синие поверхности, тонкие границы, компактная плотность, фиолетовые активные состояния и отдельные плавающие HUD-модули. Игровой инвентарь намеренно исключён.

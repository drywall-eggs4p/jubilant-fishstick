# jubilant-fishstick

A simple browser-based calculator built with HTML, CSS, and JavaScript.

## Features

- Basic arithmetic operations: addition, subtraction, multiplication, and division
- Decimal support
- Clear and delete controls
- Keyboard input support
- Responsive styling for a clean, modern UI

## Files

- `index.html` — calculator structure
- `styles.css` — layout and visual design
- `script.js` — calculator logic and interactions

## Run locally

1. Open `index.html` in a browser, or
2. Serve the project with a local static server:

```bash
python -m http.server 8000
```

Then visit `http://localhost:8000`.

## Project Composition

This repository is primarily composed of:

- JavaScript: 45%
- HTML: 28.5%
- CSS: 26.5%
